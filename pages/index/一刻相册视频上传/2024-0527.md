HEVC之前，统一的要修改 媒体创建时间（这个不修改，相册中就不会再最前面显示）


帮我写一个python脚步，用于将当前目录下的所有媒体文件（如.mp4等格式）的属性>详细信息>来源>创建媒体日期 改为当前系统时间，
包括 属性>详细信息>文件>创建时间和修改时间 改为当前系统时间、属性>详细信息>文件>名称 改为 源文件名称_当前系统时间的时间戳




你帮我把下面代码增加在控制台输入路径，然后执行，这样我不需要把文件放到对应目前去执行，这样很麻烦，另外我需要支持的格式有很多，
```python
import os
import time
import pywin32.win32file
import pywin32.win32con

# 定义一个函数来修改文件的创建时间
def change_file_creation_time(filename, creation_time):
    # 打开文件，准备修改时间属性
    handle = pywin32.win32file.CreateFile(
        filename,
        pywin32.win32file.GENERIC_WRITE,
        pywin32.win32file.FILE_SHARE_READ | pywin32.win32file.FILE_SHARE_WRITE | pywin32.win32file.FILE_SHARE_DELETE,
        None,
        pywin32.win32con.OPEN_EXISTING,
        pywin32.win32file.FILE_ATTRIBUTE_NORMAL,
        None
    )

    # 设置新的创建时间
    pywin32.win32file.SetFileTime(handle, creation_time, None, None)

    # 关闭文件句柄
    handle.close()

# 获取当前系统时间
current_time = time.time()
# 转换为时间结构
time_struct = time.localtime(current_time)
# 格式化时间为字符串
formatted_time = time.strftime('%Y%m%d%H%M%S', time_struct)
# 创建 Windows 时间格式
win_time = pywin32.win32file.Time(time.mktime(time_struct))

# 获取当前目录下的所有文件
files = os.listdir('.')

# 筛选出后缀为.mp4的媒体文件
media_files = [f for f in files if os.path.isfile(f) and f.lower().endswith('.mp4')]

for filename in media_files:
    # 修改文件的创建时间和修改时间
    os.utime(filename, (current_time, current_time))
    
    # 修改文件的 Windows 创建时间
    change_file_creation_time(filename, win_time)
    
    # 构建新的文件名
    new_filename = f"{os.path.splitext(filename)[0]}_{formatted_time}.mp4"
    
    # 重命名文件
    os.rename(filename, new_filename)

print("媒体文件的时间戳和名称已更新。")
```
