- 主要存储类别

- 主要功能模块（也是用于后台功能菜单，你帮我起名和归类）
[1] 一刻相册相关的模块包含：
1. 采集配置（一刻相册采集参数配置）
2. 全部相册（用于采集一刻相册网站的“相册 > 全部相册”页面的数据）
3. 过滤相册（过滤掉不需要被采集的相册）
4. 最近上传（一刻相册网站的“相册 > 最近上传”页面数据，仅显示最近7天保存至云端内容）
5. 人物（一刻相册网站的“相册 > 人物”页面数据，显示网站中图片包含的人物，截取出来）
6. 事物（一刻相册网站的“相册 > 事物”页面数据，显示网站中图片包含的信息，如“建筑”、“宝宝”）
[2] 云存储相关的模块包含
1. 文件
2. 相册
3. 阅读
[3] 其他的模块
1. 用户
2. 订单（已下单就是未支付、已支付）
3. 商品（会员卡、金币就是网站的虚拟货币）
4. 设置（比如注册会员送7天VIP，其他的我想不到了，你帮我补充）
5. APP升级
6. 标签（标签用于关联相册、文件、阅读的类型，如熊、猪、猴、狒、胖子等）
[4] 仪表盘相关的模块（也是网站后台主页）
1. 注册用户概览：今日新增用户	、今日活跃用户、昨日新增用户、昨日活跃用户、总用户数
2. 支付统计概况：今日下单金额（GMV）(统计时间内，下单金额（包含未支付订单）)、今日收款金额（GPV）(统计时间内，成功支付的订单金额。)
