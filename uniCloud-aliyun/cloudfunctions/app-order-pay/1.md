# 云函数目录结构设计文档

## 目录结构

```plaintext
- cloud-functions
  - app-order-pay（下单支付，查询订单等）
    - common（公共方法）
      - constants.js（常量，如数据库表名等）
      - response.js（统一响应方法，如 `createResponse(code, message, data = null)`）
      - utils.js（工具方法，如MD5加密）
      - config（支付平台配置）
        - lantu-pay-config.js（蓝兔支付配置）
        - qixiang-pay-config.js（七相支付配置）
        - caihong-pay-config.js（彩虹易支付配置）
    - modules（模块）
      - payment-platforms（第三方支付平台模块）
        - lantu-pay（蓝兔支付，仅支持微信支付）
          - api.js（蓝兔支付的API封装）
          - service.js（蓝兔支付的服务逻辑，如下单、查询等）
          - notify.js（蓝兔支付的通知处理逻辑）
        - qixiang-pay（七相支付，支持微信支付和支付宝支付）
          - api.js（七相支付的API封装）
          - service.js（七相支付的服务逻辑）
          - notify.js（七相支付的通知处理逻辑）
        - caihong-pay（彩虹易支付，仅支持支付宝支付）
          - api.js（彩虹易支付的API封装）
          - service.js（彩虹易支付的服务逻辑）
          - notify.js（彩虹易支付的通知处理逻辑）
      - unified-payment（统一支付模块，用于app发起的下单请求）
        - index.js（入口文件，导出统一支付模块的方法）
        - payment-service.js（统一支付逻辑，根据用户选择的支付方式调用不同的支付平台）
      - index.js（入口文件，导出所有模块的方法）
    - index.js（云函数URL化后的入口文件，调用云函数方法）
```

### 2. **modules/payment-platforms 目录**
每家支付平台的模块中，可以通过引入配置文件来使用相关配置。

#### **`lantu-pay/service.js`**
蓝兔支付的服务逻辑，使用配置文件。

```javascript
const lantuPayApi = require('./api');
const { createResponse } = require('../../common/response');
const lantuPayConfig = require('../../common/config/lantu-pay-config');

const lantuPayService = {
  createOrder: async (orderData) => {
    try {
      // 使用配置中的 notify_url
      orderData.notify_url = lantuPayConfig.notify_url;
      const result = await lantuPayApi.createOrder(orderData);
      return createResponse(200, 'Order created successfully', result);
    } catch (error) {
      return createResponse(500, 'Failed to create order', { error: error.message });
    }
  },
  queryOrder: async (orderId) => {
    try {
      const result = await lantuPayApi.queryOrder(orderId);
      return createResponse(200, 'Order queried successfully', result);
    } catch (error) {
      return createResponse(500, 'Failed to query order', { error: error.message });
    }
  },
};

module.exports = lantuPayService;
```

## 总结

- **独立配置文件**：每家支付平台都有独立的配置文件，方便管理和修改。
- **统一管理**：配置文件存放在 `common/config` 目录下，便于统一维护。
- **模块化设计**：每家支付平台的模块通过引入配置文件来使用相关配置，代码清晰且易于扩展。
