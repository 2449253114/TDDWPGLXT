## 详细说明

### 1. **common 目录**
存放公共方法，包括常量、统一响应方法和工具函数。

- **`constants.js`**  
  存放常量，如数据库表名、支付平台配置等。

- **`response.js`**  
  统一响应方法，封装了 `createResponse` 函数，用于返回统一的响应格式。

  ```javascript
  function createResponse(code, message, data = null) {
    return {
      code,
      message,
      data,
    };
  }

  module.exports = {
    createResponse,
  };
  ```

- **`utils.js`**  
  工具方法，如MD5加密、时间格式化等通用工具函数。

### 2. **modules 目录**
存放各个模块，包括第三方支付平台模块和统一支付模块。

#### **`payment-platforms` 目录**
存放各个第三方支付平台的模块。每个支付平台都有自己的目录，目录下包含：

- **`api.js`**  
  封装该支付平台的API请求，如发起支付、查询订单等。

  示例（蓝兔支付）：

  ```javascript
  const request = require('some-request-library');

  const lantuPayApi = {
    createOrder: async (orderData) => {
      // 调用蓝兔支付的API创建订单
      const response = await request.post('https://api.lantu.com/createOrder', orderData);
      return response.data;
    },
    queryOrder: async (orderId) => {
      // 调用蓝兔支付的API查询订单
      const response = await request.get(`https://api.lantu.com/queryOrder/${orderId}`);
      return response.data;
    },
  };

  module.exports = lantuPayApi;
  ```

- **`service.js`**  
  处理该支付平台的业务逻辑，如下单、查询订单等。

  示例（蓝兔支付）：

  ```javascript
  const lantuPayApi = require('./api');
  const { createResponse } = require('../../common/response');

  const lantuPayService = {
    createOrder: async (orderData) => {
      try {
        const result = await lantuPayApi.createOrder(orderData);
        return createResponse(200, 'Order created successfully', result);
      } catch (error) {
        return createResponse(500, 'Failed to create order', { error: error.message });
      }
    },
    queryOrder: async (orderId) => {
      try {
        const result = await lantuPayApi.queryOrder(orderId);
        return createResponse(200, 'Order queried successfully', result);
      } catch (error) {
        return createResponse(500, 'Failed to query order', { error: error.message });
      }
    },
  };

  module.exports = lantuPayService;
  ```

- **`notify.js`**  
  处理该支付平台的通知逻辑，包括 `notify_url`、`return_url` 和 `quit_url`。

  示例（蓝兔支付）：

  ```javascript
  const { createResponse } = require('../../common/response');

  const lantuPayNotify = {
    notifyUrl: async (data) => {
      // 处理蓝兔支付的异步通知
      console.log('Received lantu-pay notify:', data);
      return createResponse(200, 'Notify processed successfully');
    },
    returnUrl: async (data) => {
      // 处理蓝兔支付的同步通知（支付成功跳转）
      console.log('Received lantu-pay return:', data);
      return createResponse(200, 'Return processed successfully');
    },
    quitUrl: async (data) => {
      // 处理蓝兔支付的取消支付跳转
      console.log('Received lantu-pay quit:', data);
      return createResponse(200, 'Quit processed successfully');
    },
  };

  module.exports = lantuPayNotify;
  ```

#### **`unified-payment` 目录**
统一支付模块，用于处理app发起的下单请求。

- **`index.js`**  
  入口文件，导出统一支付模块的方法。

- **`payment-service.js`**  
  统一支付逻辑，根据用户选择的支付方式（微信或支付宝）调用不同的支付平台。

  示例：

  ```javascript
  const lantuPayService = require('../payment-platforms/lantu-pay/service');
  const qixiangPayService = require('../payment-platforms/qixiang-pay/service');
  const caihongPayService = require('../payment-platforms/caihong-pay/service');

  async function createOrder(paymentType, orderData) {
    if (paymentType === 'wechat') {
      return lantuPayService.createOrder(orderData);
    } else if (paymentType === 'alipay') {
      return caihongPayService.createOrder(orderData);
    } else {
      throw new Error('Unsupported payment type');
    }
  }

  module.exports = {
    createOrder,
  };
  ```

## 总结

- **独立通知地址**：每家支付平台都有独立的 `notify.js` 文件，处理通知逻辑。
- **统一入口**：在 `app-order-pay\index.js` 中统一引入和导出各家的通知地址。
- **清晰命名**：每家支付平台的通知地址命名清晰，易于区分。
